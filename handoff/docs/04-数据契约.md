# 数据契约（现存四份核心结构）

> 这四份结构是整个系统的「接口」。改它们 = 改架构，请对照 `01-技术方案.md` 的增量改造原则。
> 完整 zod 定义见 `source/backend/src/modules/design-assistant/domain/design-assistant.schemas.ts` 与 `design-spec.schemas.ts`。

---

## 1. `SceneAnalysis`（视觉模型的画面理解结果）

| 字段 | 类型 | 说明 |
|---|---|---|
| `summary` | string ≤500 | 一句话概括画面与卖点 |
| `subjects` | string[≤8] | 主体 label 列表（按重要性） |
| `subjectRegions[]` | 见下表 | 主体区域 |
| `environment` | string | 场景（缺省回退 `background.description`） |
| `background` | `{description, complexity: clean\|moderate\|busy, textFriendly: boolean}` | 背景信息 |
| `dominantColors` | hex[1–6] | 画面主色（供 L1 配色推导、L2 判断色调） |
| `safeZones[]` | `{x,y,width,height,reason,colors?}` | 文字安全区（含底色，用于算对比度） |
| `marketingTone` | string[≤5] | 营销调性标签（复古潮流 / 暗调质感…） |
| `risks` | string[≤4] | 排版风险 |

`subjectRegions[]` 细分：

| 字段 | 说明 |
|---|---|
| `label` | 8–24 字，含位置与外观线索，例如「左侧真人模特（金色短发+墨镜黑卫衣）」 |
| `x/y/width/height` | 归一化外接矩形（0–1） |
| `points[]` | 沿「主体外侧避让边界」采样的点（顺时针，**提示词只要 20 个**，schema 上限 100 保护） |
| `confidence` | 0–1 |
| `score` | **0–100 主体价值分**（面积/清晰度/居中程度/是否代表卖点）。前端 ≤60 默认不选；缺省按 `confidence × 面积^0.35` 估算 |
| `importance` | primary / secondary |
| `colors[]` | 主体代表色 1–3 个（文字与特效要避开这些色相） |

## 2. `LayoutPlan`（L1 纯代码构图决策）

| 字段 | 说明 |
|---|---|
| `subjectCount` / `areaRatio` / `scale` | 主体数量、像素并集覆盖率、体量档位（small/medium/large） |
| `selection` | `all` / `explicit` / `unmatched`（主体筛选状态） |
| `grid` | 决策网格 `{cols, rows}`，按画幅比例自适应（3×3 / 3×4 / 4×3） |
| `textAnchor` | 主文字承载区 `AnchorSpan`（单格或合并出的横/竖带） |
| `secondaryAnchor` | 收尾小字承载区，可能为 `null` |
| `strategy` | `full-bleed` / `full-band` / `side-block` / `column-stack` / `edge-small` / `wrap-subject` |
| `headlineSizeRange` | 主标题字号建议区间（相对短边） |
| `palette` | 特效/文字配色候选（含 `text`、`suggested.accent/support`、`options[]`，每个候选带对比度） |
| `candidates[]` | 决策格评分明细（heat / safe / score），前端画热区网格 |
| `designerBrief` | 直接拼进 L2 提示词的一段中文说明 |
| `rationale` | 给人看的决策解释（前端展示） |

`AnchorSpan`：`{id, label, colStart, colEnd, rowStart, rowEnd, heat, safe, score, cells}`。

## 3. `DesignSpec`（L2 输出，**无坐标、无毫秒**）

```jsonc
{
  "version": 1,
  "concept": "一句话设计概念/理由（≤160 字，只给人看，不渲染）",
  "blocks": [ /* 1–5 个，见下表 */ ],
  "effects": [ /* 0–3 个，见下表 */ ],
  "palette": { "text": "#RRGGBB", "accent": "…?", "support": "…?" },
  "beats": { "pace": "slow|medium|fast", "startMs": 0 }
}
```

`blocks[]`：

| 字段 | 取值 / 范围 | 说明 |
|---|---|---|
| `id` | 小写字母数字连字符 | 唯一 |
| `role` | `headline` / `subline` / `paragraph` / `meta` / `kicker` | 必须恰好 1 个 headline |
| `text` | headline 4–14 字；paragraph ≤30；其余 ≤40 | 必须是画面文案（见文案正反例） |
| `anchor` | `{ref, dxPct, dyPct}` | `ref ∈ textAnchor / secondaryAnchor / safeZone:<i> / free`；偏移 ±8% |
| `align` | `left` / `center` / `right` | 同锚点 + 同对齐 = 同一文字组 |
| `sizeRatio` | 0.015–0.2（headline 建议 0.06–0.16） | 字号占画面短边比例 |
| `weight` | 300–900 | 会取整到 100 的倍数 |
| `tracking` | -0.1–0.3 | 字距（em） |
| `lineHeight` | 倍数 | 行高 |
| `font` | `sans` / `serif` / `display` / `mono` | 字体族（渲染器映射到系统字体栈） |
| `transform` | `{scaleX, scaleY, rotateDeg, skewDeg}` | 夹取：0.4–2 / 0.4–2 / ±25° / ±20° |
| `path` | `{fromDxPct, fromDyPct, fromScale, toScale}` | 运动路线（起点偏移与首尾缩放），夹取 ±60% / 0.3–2 |
| `text3d` | `none` / `cylinder` / `cube` | **仅 headline**，其它角色强制回 `none` |
| `occlude` | boolean | 文字与主体重叠（饱和度渐变混色，非遮挡挖除） |
| `enter` | `{id, params, options}` | 文字入场动效，id 必须在动效目录内 |
| `idle?` | `{id, params, options}` | 循环微动（`float-y` / `breathe`） |

`effects[]`：

| 字段 | 说明 |
|---|---|
| `id` | 动效目录里的光效 id（见 `prompts/03-motion-catalog.prompt.md`） |
| `anchor` | 同 blocks 的锚点结构（整幅滤镜类忽略锚点，固定居中） |
| `colorRef` | `accent` / `text` / `support` / 十六进制（不在 L1 候选里会回退默认色） |
| `params` | 数值参数，越界会被夹到目录范围 |
| `options` | 枚举选项：`style` / `mode` / `glyph` / `pattern` |

### 3.1 validator 夹取清单（`design-spec.validator.ts`）

| 规则 | 行为 |
|---|---|
| blocks > 5 / effects > 3 | 截断并记 issue |
| 重复 headline | 降级为 subline |
| 没有 headline | 把第一块提升为 headline |
| 重复 id | 自动加后缀 |
| 未知锚点 | 回退 `textAnchor` |
| 偏移越界 | 夹到 ±8% |
| 颜色不在 L1 候选 | 回退默认正文色 |
| 字数超限 | 按 role 截断（headline 14 / paragraph 30 / 其它 40） |
| 文本像设计说明或图片描述 | 命中 40+ 关键词（描边/镭射/俯拍/色调/反差…）→ 记 issue 并从画面移除（headline 保留） |
| 非 headline 的 `text3d` | 强制 `none` |
| 动效参数/枚举非法 | 按目录夹取，逐条记 issue |
| issues > 0 | 用例层带着 issues 再请模型一次，取 issues 更少的结果 |

## 4. `CompositionSpec`（L3 输出，可直接渲染）

```jsonc
{
  "version": 1,
  "durationMs": 3000,
  "layers": [
    {
      "id": "headline",
      "kind": "text",              // text | pulse
      "role": "headline",
      "text": "曼谷 · 第二场",
      "size": 0.115,               // 相对短边
      "weight": 800,
      "tracking": -0.02,
      "align": "left",
      "font": "display",
      "text3d": "cylinder",
      "transform": { "scaleX": 1, "scaleY": 1, "rotateDeg": 0, "skewDeg": 0 },
      "occlude": false,
      "enter": {
        "type": "stand-up-3d",
        "startMs": 0,
        "durationMs": 860,
        "ease": "outCubic",
        "from": { "dx": 0.08, "dy": 0, "scale": 1.12 },
        "toScale": 1,
        "perspectiveDeg": 28
      },
      "idle": { "type": "float-y", "amplitude": 0.004, "periodMs": 2600 },
      "startMs": 0,
      "endMs": 3000,
      "x": 0.1,                   // 归一化锚点（对齐方式决定它代表左/中/右）
      "y": 0.184,
      "color": "#F6F8F9"
    },
    {
      "id": "effect-1",
      "kind": "pulse",
      "animation": "outline",      // sweep|drift|dot|outline|marker|laser|glow|soft|strobe|breathe
      "size": 0.006,
      "startMs": 200,
      "endMs": 3000,
      "x": 0.5,
      "y": 0.5,
      "color": "#D9FF52",
      "params": { "widthPct": 0.6, "durationMs": 1600, "opacity": 0.8, "jitterPct": 0.6 },
      "style": "spray-solid",      // 枚举选项按需出现
      "mode": "draw-on"
    }
  ]
}
```

### 4.1 L3 解算规则（`compose-canvas.ts`）

| 规则 | 值 / 说明 |
|---|---|
| 边距 | `EDGE_MARGIN = 0.1`（四周 10%） |
| 文字分组 | `anchor.ref + align` 相同 → 同一组；`dxPct/dyPct` 只作整组微调 |
| 组内堆叠 | 按 role 顺序：kicker → headline → subline → paragraph → meta；块间距 25% |
| 重叠消解 | 最多 6 轮「把下面的块往下推」，避免文字互相压住 |
| 时长 | `STAGGER_MS = 140`；`PACE_FACTOR {slow:1.25, medium:1, fast:0.8}` |
| 特效避让 | 光效中心落在文字盒内 → 先向右/左让开，再退到文字块下方；整幅滤镜（laser/glow/soft/strobe）固定居中且不参与避让 |
| 收尾 | `constrainCompositionToScene(spec, analysis, { keepLayout: true })`：只夹边界 + 补 animation，不再把文字搬进 safeZone |

### 4.2 渲染契约（前端）

- `createEffectTimeline(layers, durationMs)`
  - `snapshot()` → 静态封面：`{ progress: 0.55, enterProgress: 1, staticFrame: true }`，**所有效果画最终形态**。
  - `sample(t)` → 播放态，按 `startMs/endMs` 过滤并算 `progress`。
- `RenderOptions.subjectRegions` 供三处使用：`subject-outline` 描边路径、`occlude` 重叠混色、`constrainCompositionToScene` 的主体避让判断（服务端侧）。
