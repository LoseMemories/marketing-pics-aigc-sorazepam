# 提示词片段 · 文案正反例（`domain/copy-rules.catalog.ts`）

用来压制三类错误文案：① 图片描述（视角/构图/色调）② 设计心思（反差/层次/描边）③ 主体外观罗列（黑卫衣/迷彩裤/鞋）。
当前条目：反例 21 条、正例 24 条、改写对照 10 组。

## 实际注入提示词的文本

```text
【文案能写什么 / 不能写什么（正反例，务必逐条对照）】
三条禁令：
① 禁止描述图片本身：视角、构图、光线方向、色调、材质反光、器材、景别，一律不写。
② 禁止写设计心思与手法：反差、层次、留白、呼吸感、视觉重心、描边、压字，这些只写进 concept。
③ 禁止描写主体与画面的基础特征：衣服颜色/款式、裤子、鞋、发型、镜头的距离与角度、整体色调；
   只有资料里明确写「突出单品」「突出穿搭」「突出摄影」时，才允许写这几项，而且必须挑资料提到的单品；
   资料只是顺带提一句「我很满意那天的穿搭」而没说「要突出」，也算不允许。

反例（看到这种写法就重写）✗：
- 内场仰视 · 空山基金色立像，金属光泽压着整片蓝天
- 俯拍视角，人物占据画面左侧三分之一
- 逆光勾边，暖橙与冷灰撞出强烈对比
- 低角度特写，背景大面积虚化
- 冷灰色调里的一抹暖光，构图留白在右侧
- 金属质感的反光落在肩线，色调偏青
- 中景平视，背景是爬满藤蔓的砖墙
- 大面积留白 + 主体居中，典型的杂志封面构图
- 趣味反差，让暖光与冷墙互相咬合
- 用描边圈住主体，视线自然被拉过去
- 文字压在人物后方，制造前后层次
- 视觉重心放在右下角，节奏有呼吸感
- 字距拉开，做出高级的留白感
- 加一层柔光，让画面更有电影感
- 冷暖对冲的层次，把情绪推上去
- 黑卫衣 × 迷彩工装裤 × 棕色工装靴
- 金色短发配墨镜，黑色上衣搭迷彩裤
- 用 50mm 定焦拍的，皮肤质感很干净

正例（这才是画面文案）✓：
- 南锣鼓巷 · 深秋傍晚
- 傍晚的灰墙很冷，窗里的光很暖
- 深秋的光，穿在身上
- 从灯光里讨一点温暖
- 秋天的最后一个逛街日
- 老街的窗还亮着
- 冷风吹过来，先躲在光里
- 手作陶器 · 今日新出窑
- 等一壶水开的时间
- 把下午留给这间小店
- 复古潮流 · 今秋限定
- 街头感刚好，不必用力
- 旧东西有旧东西的脾气
- 手缝的边，比机器多一道线
- 三十年的手艺，只做这一种碗
- 周末来坐坐，茶是热的
- 限时三日 · 到店试穿
- 山野民宿 · 十月的第一场雾

可以放心使用的信息类型：
- 地点 / 街区 / 城市（资料里出现过的真实地名）
- 季节、节气、时间感（深秋、傍晚、开春、凌晨）
- 客观风格 tag（复古潮流、街头感、侘寂、户外机能）
- 资料里明确提到的商品类别、材质、工艺、尺寸、产地
- 资料里明确提到的卖点：限量、手工、当季、可试穿、可预约等
- 情绪与场景结论（把喧嚣留在门外、从灯光里讨一点温暖）
- 行动号召（到店试穿、周末来坐坐、限时三日）

改写示范（左边是错的，右边才是该写的）：
- ✗ 内场仰视 · 空山基金色立像，金属光泽压着整片蓝天
  ✓ 山门口的金像，今天落成了（删掉视角与材质描述，只说发生了什么）
- ✗ 俯拍视角，黑卫衣配迷彩工装裤，冷灰色调
  ✓ 深秋傍晚 · 街头感刚好（穿搭与色调是画面特征；除非资料要求突出单品，否则改写成季节与调性）
- ✗ 趣味反差，暖光与冷墙互相咬合
  ✓ 墙是冷的，窗里的光是暖的（设计心思不能上画面；把它还原成用户能读到的感受）
- ✗ 文字压在人物后方，制造前后层次
  ✓ 把秋天穿在身上（动效与版式属于 concept，不属于画面文案）
- ✗ 暖橙色调里，藤蔓爬满了整面砖墙
  ✓ 十月，藤蔓还没褪色（去掉色调与构图，只保留可以被拍成故事的事实）
- ✗ 手作陶碗 · 复古文艺 · 柔和暖光
  ✓ 手作陶碗 · 今日出窑（客观 tag 可以留（手作陶碗），画面光线描述要删）
- ✗ 逆光拍摄，皮肤通透，发丝有光
  ✓ 傍晚的光，刚好落在发梢（摄影技巧只在资料要求突出摄影时才写，否则换成情绪）
- ✗ 大片留白，主体靠左，构图稳定
  ✓ 把喧嚣留在画面之外（构图描述不是文案；留白的感受可以是）
```
