# 设计素材爬取方案（聚焦版 v3）

> 目标：抓取 **100 条「带设计」的博客主图 / 营销贴 / 封面图**，验证落库前标签准确度。
> 原则：**只爬设计成品类素材**，不抓裸照片；**每个来源只爬它擅长的主题**；**不逐张猜 topic**。

## 1. 范围

| 项 | 值 |
|---|---|
| 数量 | 100 条 |
| 内容类型 | 带设计的博客主图 / 营销贴 / 封面图（网页 Hero、海报、封面） |
| 主源 | MotionSites（motionsites.org）——网页/营销主图，SSR 可解析、结构干净 |
| 供给四元组 | 设计内容 + 示例图 |

## 2. 来源优势（本次只用主源，其余后续按需补）

| 网站 | 优势 | 本批是否用 |
|---|---|---|
| MotionSites | 网页/营销 Hero 主图、渐变、动效配方 | ✅ 主源 |
| Awwwards / Lapa | 获奖网页 Hero | 后续 |
| Vogue / GQ / Rolling Stone | 杂志封面 | 后续（版权走缩略图） |
| Billboard / Dribbble / Behance | 海报 / 营销贴 | 后续 |

## 3. 契约（raw.json，聚焦版）

```jsonc
{
  "site": "motionsites",
  "sourceQuery": "Hero",          // 爬取来源（站内分类），topic 由它映射，不逐张猜
  "category": "Hero",
  "topic": "网页设计",             // 由 sourceQuery 映射（落库方最终定）
  "url": "https://motionsites.org/prompts/<slug>",
  "title": "Cargo Group",
  "description": "",               // 付费墙时留空
  "author": "MotionSites",
  "siteTags": [],
  "isDesigned": true,
  "popularity": { "award": "curated", "note": "paid" },
  "width": 1536, "height": 1152,   // 取最大档
  "license": "reference-only",
  "capturedAt": "..."
}
```

## 4. 质量规则

1. 图片取 `srcSet` 最大档（w=1536），不取 640。
2. 按 slug 去重。
3. 付费墙项 `description` 留空 + `popularity.note="paid"`。
4. `isDesigned` 恒为 true。

## 5. 验收

- 数量 = 100，字段完整（url/title/category/site/width/height/license/capturedAt）。
- title / category / 图片三者一一对应，无错配。
