## 3. 接口契约

### 批量上传

```
POST /api/v1/workflow/batch
  multipart: files=@a.webp files=@b.webp …（字段名任意，按顺序遍历）
→ 202 { batchId: "uuid", total: 2 }

GET /api/v1/workflow/batches
→ { batches: [{ id, title, createdAt, status, total, done, failed, items[] }] }

GET /api/v1/workflow/batches/:id
→ { id, title, status, total, done, failed, items: [{ name, base, status, error? }] }
```

- `status`: `analyzing` | `done`
- 清单落在 `uploads/.batches/<id>.json`，**重启后可恢复**
- 队列**严格串行**（SAM/OCR 是 CPU 密集，避免 OOM）

### 灵感库

```
GET /api/v1/gallery/motionsites
→ {
    categories: [...],
    folders: [{ id, title, total, done, failed, status, createdAt, cover }],
    items:   [{ …, batchId, autoCategory, tags: ["uploads","magazine"] }]
  }
```

- `autoCategory` 由 `meta.category` / `meta.tags` 中命中字典的值推导；无则 `null`（前端「未归类」）。

### 落库

```
POST /api/v1/workflow/save
  { pendingId, category }
```

- `category` 为空或 `"uploads"` → 只写 `tags: ["uploads"]`，`category: null`（即「未归类」）

### 删除（含文件夹退化）

```
DELETE /api/v1/workflow/uploads/:base
→ { ok, deleted, dissolved, remaining }
```

- 若该素材属于某批次：从清单移除并递减计数
- 剩 **≤1 张** → 删清单、最后一张 `batchId` 置 null、返回 `dissolved: true`
